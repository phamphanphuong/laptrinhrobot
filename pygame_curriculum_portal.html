Tư Duy Hướng Đối Tượng: Phân Tích Thực Thể

Thiết lập kiến trúc trước khi gõ dòng code đầu tiên

Giáo viên hướng dẫn học sinh lập tài liệu thiết kế trò chơi (Game Design Document):

  • Game có những Class (Thực thể) nào? Gồm 3 Class chính: Player (Tàu người chơi điều khiển), Enemy (Thiên thạch rơi xuống), Bullet (Tia đạn laser bắn ra).
  • Quy luật rơi của Thiên thạch là gì? Khởi tạo ở tọa độ Y âm (ngoài màn hình phía trên), X ngẫu nhiên. Vận tốc Y dương (rơi xuống). Khi vượt qua đáy màn hình thì reset tái sinh lên đỉnh.
  • Xử lý va chạm thế nào? - Nhóm Bullets chạm Enemies → Cả hai biến mất, tích lũy điểm số.
    - Nhóm Enemies chạm Player → Trừ máu hoặc Game Over.

Từ Tư Duy Đến Dòng Mã Lệnh

Phân rã bài toán lớn thành các Class độc lập giúp học sinh không bị ngợp khi đối diện với các file mã nguồn dài. OOP giúp mô hình hóa game logic trực quan như ngoài đời thực.

Thực Hành Viết Code: Lớp Enemy Kế Thừa Sprite

Tạo thực thể thiên thạch bay trong file `enemy.py`

Học sinh tự tay viết mã nguồn định nghĩa thực thể `Enemy` kế thừa từ lớp `pygame.sprite.Sprite`:

enemy.py
import pygame
import random

class Enemy(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        # Load hình ảnh thiên thạch và lấy khung hình chữ nhật (rect)
        self.image = pygame.image.load("assets/meteor.png").convert_alpha()
        self.rect = self.image.get_rect()
        
        # Vị trí xuất hiện ngẫu nhiên ở mép trên màn hình
        self.rect.x = random.randrange(0, 800 - self.rect.width)
        self.rect.y = random.randrange(-100, -40)
        
        # Tốc độ rơi ngẫu nhiên
        self.speedy = random.randrange(2, 6)

    def update(self):
        # Cập nhật tọa độ Y để thiên thạch rơi xuống
        self.rect.y += self.speedy
        
        # Nếu rớt khỏi đáy màn hình (HEIGHT = 600) -> Tái sinh lên đỉnh
        if self.rect.top > 600 + 10:
            self.rect.x = random.randrange(0, 800 - self.rect.width)
            self.rect.y = random.randrange(-100, -40)
            self.speedy = random.randrange(2, 6)

Nâng Cấp Game & Kỹ Năng Quản Lý Git

Cá nhân hóa tựa game và lưu trữ mã nguồn chuyên nghiệp

Tính năng thử thách học sinh tự mở rộng:

  • Thiên thạch xoay tròn: Dùng pygame.transform.rotate() để thiên thạch xoay quanh tâm khi rơi.
  • Âm thanh nổ vang: Nạp file .wav, phát âm thanh khi groupcollide phát hiện trúng đạn.
  • Tăng độ khó động: Khi Score > 1000, tự động tăng tốc độ rơi `speedy` lên mức 6-12.

Kỹ Năng Kỹ Sư Thực Thụ (Git & GitHub)

Mã nguồn không chỉ lưu trong máy tính cá nhân. Trẻ được hướng dẫn tạo Repository, commit code, tạo README giới thiệu dự án và quản lý phiên bản như một lập trình viên đích thực.

git commit -m "feat: add shooting collision"
