Tại Sao Nên Học ESP32 Bằng MicroPython?

Thay vì sử dụng C/C++ khô khan với cú pháp con trỏ phức tạp, MicroPython mở ra cánh cửa sáng tạo phần cứng nhanh chóng, trực quan và hiện đại nhất cho học sinh lứa tuổi THCS & THPT.

Cú Pháp "Sạch" & Dễ Hiểu

Không còn lỗi thiếu dấu chấm phẩy ; hay rò rỉ bộ nhớ con trỏ như C++. Python ép học sinh viết code thụt lề chuẩn chỉ, cấu trúc như tiếng Anh, giúp các em tập trung vào tư duy thuật toán thay vì đánh vật với cú pháp.

Tương Tác Thời Gian Thực (REPL)

Với Thonny IDE, học sinh gõ lệnh led.value(1) và đèn thực tế sáng lên ngay lập tức! Không tốn vài phút chờ nạp biên dịch (compile) như Arduino. Việc gỡ lỗi (Debug) trở nên siêu tốc, sinh động và đầy cảm hứng.

Hệ Sinh Thái Mạng Sẵn Có

Sức mạnh vượt trội của ESP32 là Wi-Fi & Bluetooth. MicroPython cung cấp các module chuẩn socket, urequests, umqtt.simple. Học sinh có thể tự tạo Web Server, gửi cảnh báo Telegram, tạo Smart Home chỉ với vài chục dòng code.

Lộ Trình Masterclass ESP32: 48 Buổi

Thiết kế cho hành trình 9 - 12 tháng. Đủ sâu và thực chiến để học sinh THCS/THPT hoàn toàn làm chủ ngôn ngữ Python và chế tạo thiết bị IoT độc lập.

Nền Tảng MicroPython & Tín Hiệu Cơ Bản

Buổi 1 - 12 (3 Tháng)

Học sinh nạp firmware MicroPython vào chip ESP32. Học cú pháp Python chuẩn và cách điều khiển tín hiệu Điện tử cơ sở qua chân GPIO.

  • B1-B4 (Core Python & Thonny): Cài đặt driver CP2102/CH340, nạp firmware MicroPython. Biến, kiểu dữ liệu, cấu trúc rẽ nhánh if/elif, vòng lặp for/while, Functions, Lists.
  • B5-B8 (Digital Out & PWM): Thư viện machine.Pin. Nháy LED, mô phỏng đèn giao thông ngã tư. Băm xung PWM (machine.PWM) làm hiệu ứng đèn nhịp thở (Breathing LED) và điều chỉnh độ sáng.
  • B9-B12 (Digital In & ADC): Xử lý nút nhấn, kỹ thuật chống dội phím (Debounce). Bộ chuyển đổi tương tự - số (ADC 12-bit) đọc Biến trở, cảm biến ánh sáng quang trở (LDR) làm đèn tự bật khi trời tối.

Giao Tiếp Cảm Biến & Cơ Cấu Chấp Hành

Buổi 13 - 24 (3 Tháng)

Giao tiếp với các module phức tạp qua chuẩn giao tiếp công nghiệp. Thu thập dữ liệu thực tế và tạo phản hồi vật lý linh hoạt.

  • B13-B16 (Chuẩn Bus I2C): Nguyên lý bus 2 dây SDA/SCL. Giao tiếp hiển thị dữ liệu lên màn hình LCD 16x2 (I2C Backpack) và màn hình OLED SSD1306 (128x64). Lập trình vẽ hình học và hoạt ảnh trên OLED.
  • B17-B20 (Advanced Sensors): Đọc nhiệt độ và độ ẩm số (DHT11/DHT22) với thư viện dht. Đo khoảng cách chính xác bằng cảm biến siêu âm (HC-SR04) để làm radar lùi xe và đo mực nước bồn chứa.
  • B21-B24 (Actuators & Sound): Điều khiển góc quay động cơ Servo SG90 (Làm barie đỗ xe tự động). Lập trình góc quay động cơ bước (Stepper 28BYJ-48). Phát nốt nhạc giai điệu qua còi chíp Buzzer PWM.

Khai Phá Mạng Wi-Fi & Internet (IoT)

Buổi 25 - 36 (3 Tháng)

Cốt lõi của khóa học. Đưa phần cứng cục bộ kết nối mạng toàn cầu thông qua chip Wi-Fi tích hợp sẵn của ESP32.

  • B25-B28 (Local Web Server): Dùng thư viện network.WLAN và socket. ESP32 tự tạo Access Point hoặc kết nối Router nhà, host một trang HTML để điều khiển thiết bị trực tiếp qua trình duyệt điện thoại.
  • B29-B32 (Giao thức MQTT & Cloud IoT): Kiến trúc Publish/Subscribe. Đẩy dữ liệu cảm biến lên nền tảng đám mây (Adafruit IO, Blynk IoT, HiveMQ). Thiết kế App Dashboard trên điện thoại để điều khiển từ bất cứ đâu qua 4G/5G.
  • B33-B36 (HTTP REST API & NTP): Thư viện urequests. Gọi API lấy dữ liệu thời tiết thực tế (OpenWeatherMap) và đồng bộ đồng hồ mạng chính xác tới từng giây qua giao thức NTP.

Mô Phỏng Bài Giảng: Local Web Server

Trải nghiệm Bài học số 26: Dùng MicroPython với thư viện Socket tiêu chuẩn để biến ESP32 thành Web Server điều khiển thiết bị qua điện thoại di động.

1

Mô Hình Client - Server Với Python Sockets

Hiểu tường tận cách các thiết bị trên mạng giao tiếp với nhau trước khi gõ dòng code đầu tiên.

Trong mô hình mạng IoT cục bộ, mỗi bên đảm nhiệm một vai trò rõ ràng:

  • 1. Ai là Client? Ai là Server? Điện thoại di động hoặc Laptop của bạn là Client (Bên gửi yêu cầu). Bo mạch ESP32 đóng vai trò là Web Server (Bên tiếp nhận và xử lý yêu cầu).
  • 2. Kết nối Wi-Fi & Cấp phát IP: ESP32 dùng module network.WLAN(network.STA_IF) kết nối vào Access Point nhà bạn, nhận địa chỉ IP nội bộ (ví dụ: 192.168.1.150).
  • 3. Xử lý Request HTTP (Socket): Khi Client truy cập IP, ESP32 gửi trả mã HTML chứa các nút bấm. Khi người dùng bấm nút "Bật Đèn", trình duyệt gửi request GET /?led=on HTTP/1.1. ESP32 phân tích chuỗi ký tự này và lệnh cho chân GPIO bật Relay!

2

Lập Trình MicroPython Trong Thonny IDE

Học sinh sử dụng thư viện socket mở cổng 80 chuẩn HTTP và bóc tách chuỗi HTTP Header truyền đến.

main.py - Thonny MicroPython (ESP32 @ COM3)
MicroPython v1.22 
import machine
import network
import socket

# 1. Khởi tạo chân GPIO số 2 nối với LED onboard hoặc Module Relay
led = machine.Pin(2, machine.Pin.OUT)

# 2. Hàm sinh mã HTML cho trang giao diện điều khiển
def web_page():
    led_state = "ON (BẬT)" if led.value() == 1 else "OFF (TẮT)"
    html = f"""<!DOCTYPE html><html>
    <head>
        <meta name="viewport" content="width=device-width, initial-scale=1">
        <title>ESP32 Smart Home</title>
        <style>body {{ font-family: sans-serif; text-align: center; padding: 40px; background: #0f172a; color: white; }}
               .btn {{ padding: 15px 30px; font-size: 18px; border-radius: 12px; border: none; cursor: pointer; }}
               .btn-on {{ background: #22c55e; color: white; }} .btn-off {{ background: #ef4444; color: white; }}</style>
    </head>
    <body>
        <h1>ESP32 Smart Home Dashboard</h1>
        <p>Trạng thái đèn hiện tại: <strong>{led_state}</strong></p>
        <p><a href="/?led=on"><button class="btn btn-on">BẬT ĐÈN</button></a>
           <a href="/?led=off"><button class="btn btn-off">TẮT ĐÈN</button></a></p>
    </body></html>"""
    return html

# 3. Mở Socket lắng nghe cổng 80 (HTTP Server)
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.bind(('', 80))
s.listen(5)
print("Server đang chạy trên cổng 80... Sẵn sàng nhận kết nối!")

# 4. Vòng lặp chính tiếp nhận Client
while True:
    conn, addr = s.accept()
    print("Kết nối từ:", addr)
    request = conn.recv(1024)
    request_str = str(request)
    
    # Phân tích lệnh GET
    if '/?led=on' in request_str:
        led.value(1)
        print("=> Lệnh: BẬT ĐÈN")
    elif '/?led=off' in request_str:
        led.value(0)
        print("=> Lệnh: TẮT ĐÈN")
        
    # Trả về trang Web cho Client
    response = web_page()
    conn.send('HTTP/1.1 200 OK\r\n')
    conn.send('Content-Type: text/html\r\n')
    conn.send('Connection: close\r\n\r\n')
    conn.sendall(response.encode())
    conn.close()
Shell: Server đang chạy trên cổng 80... Sẵn sàng nhận kết nối! ESP32 Connected
3

Triển Khai & Bài Tập Mở Rộng Kỹ Sư

Từ thử nghiệm trên máy tính đến hệ thống phần cứng độc lập hoạt động 24/7.

3 Bước Hoàn Thiện Dự Án Của Học Viên:

  • 1. Chạy Code Trực Tiếp (F5): Bấm F5 trên Thonny IDE. Khung Shell thông báo địa chỉ IP tức thì (VD: 192.168.1.150). Không cần tốn thời gian biên dịch lại.
  • 2. Điều Khiển Qua Trình Duyệt: Mở Safari hoặc Chrome trên iPhone/Android, nhập IP vào thanh địa chỉ. Bấm nút và nghe tiếng rơ-le (Relay) đóng ngắt "tách tách" bật tắt đèn thật!
  • 3. Lưu Vào Chip & Chạy Độc Lập: Lưu file với tên main.py trực tiếp vào bộ nhớ Flash của ESP32. Rút cáp khỏi máy tính, cắm sạc dự phòng: Thiết bị tự động khởi động và host web độc lập!
