Tại Sao Nên Học ESP32 Bằng MicroPython?

Thay vì sử dụng C/C++ khô khan với cú pháp phức tạp, Python mở ra cánh cửa sáng tạo phần cứng nhanh chóng và trực quan nhất cho học sinh.

Cú Pháp "Sạch" & Dễ Hiểu

Không còn lỗi thiếu dấu chấm phẩy `;` hay lỗi biên dịch bộ nhớ như C++. Python ép học sinh viết code thụt lề chuẩn chỉ, cấu trúc như tiếng Anh, giúp các em tập trung vào tư duy thuật toán thay vì đánh vật với cú pháp.

Tương Tác Thời Gian Thực (REPL)

Với Thonny IDE, học sinh gõ lệnh led.value(1) và đèn thực tế sáng lên ngay lập tức! Không tốn vài phút chờ biên dịch (compile) như Arduino. Việc gỡ lỗi (Debug) trở nên siêu tốc và hứng thú.

Thư Viện Internet Đồ Sộ

Sức mạnh của ESP32 là Wi-Fi. MicroPython cung cấp các thư viện socket, requests, mqtt cực kỳ dễ dùng. Trẻ có thể tự tạo Web Server, gửi tin nhắn Telegram, làm Nhà thông minh chỉ với vài chục dòng code.

Lộ Trình Masterclass ESP32: 48 Buổi

Thiết kế cho hành trình 9 - 12 tháng. Đủ sâu để học sinh hoàn toàn làm chủ ngôn ngữ Python và chế tạo thiết bị IoT độc lập.

Nền Tảng MicroPython & Tín Hiệu Cơ Bản

Buổi 1 - 12

Học sinh nạp firmware MicroPython vào chip ESP32. Học cú pháp Python chuẩn và cách điều khiển tín hiệu Điện tử cơ sở.

  • B1-B4 (Core Python): Cài đặt Thonny IDE. Biến, Kiểu dữ liệu, Cấu trúc if/elif, Vòng lặp for/while, Functions, Lists.
  • B5-B8 (Digital & PWM): Thư viện machine.Pin. Nháy LED, Đèn giao thông. Băm xung PWM làm hiệu ứng đèn nhịp thở (Breathing LED).
  • B9-B12 (Input & ADC): Xử lý nút nhấn, Kỹ thuật chống dội phím (Debounce). Bộ chuyển đổi tương tự-số (ADC) đọc Biến trở, Cảm biến ánh sáng (LDR).

Giao Tiếp Cảm Biến & Cơ Cấu Chấp Hành

Buổi 13 - 24

Giao tiếp với các module phức tạp qua chuẩn giao tiếp công nghiệp. Thu thập dữ liệu thực tế và tạo phản hồi vật lý.

  • B13-B16 (I2C Protocol): Nguyên lý bus I2C. Giao tiếp hiển thị dữ liệu lên màn hình LCD 16x2 và OLED SSD1306. Lập trình vẽ hình học trên OLED.
  • B17-B20 (Advanced Sensors): Đọc nhiệt độ/độ ẩm số (DHT11/DHT22). Đo khoảng cách chính xác bằng sóng siêu âm (HC-SR04) để làm radar lùi xe.
  • B21-B24 (Actuators): Điều khiển góc quay Động cơ Servo (Làm barie cửa tự động). Lập trình Động cơ bước (Stepper). Phát nốt nhạc qua còi Buzzer.

Khai Phá Mạng Wi-Fi & Internet (IoT)

Buổi 25 - 36

Cốt lõi của khóa học. Đưa phần cứng cục bộ kết nối toàn cầu thông qua chip Wi-Fi của ESP32.

  • B25-B28 (Local Web Server): Dùng thư viện network và socket. ESP32 tự host một trang HTML để điều khiển thiết bị qua trình duyệt điện thoại.
  • B29-B32 (MQTT Protocol): Kiến trúc Publish/Subscribe. Đẩy dữ liệu cảm biến lên nền tảng đám mây (Adafruit IO, Blynk IoT).
  • B33-B36 (HTTP API): Thư viện urequests. Gọi API lấy dữ liệu thời tiết (OpenWeatherMap) thời gian thực và đồng bộ đồng hồ (NTP).

Smart Home & Đồ Án Tốt Nghiệp

Buổi 37 - 48

Gắn kết tất cả kiến thức. Đóng gói sản phẩm phần cứng, xử lý điện áp cao và triển khai dự án Hackathon.

  • B37-B40 (Security & 220V): Điều khiển Module Relay đóng ngắt quạt/đèn 220V thực tế. Giao tiếp SPI đọc thẻ từ bảo mật (RFID RC522).
  • B41-B44 (Telegram Bot): Lập trình ESP32 tự động gửi tin nhắn/cảnh báo vào nhóm chat Telegram của gia đình khi có trộm hoặc cháy nổ.
  • B45-B48 (Hackathon Final): Tự thiết kế và chế tạo sản phẩm lớn (Nhà kính thông minh tự tưới, Hệ thống cửa nhận diện vân tay/thẻ, Trạm quan trắc khí hậu). Bảo vệ đồ án.

Mô Phỏng Bài Giảng: Local Web Server

Trải nghiệm Bài học số 26: Dùng MicroPython thư viện Socket để điều khiển đèn nhà qua điện thoại di động.

1

Client - Server với Python Sockets

Trước khi gõ code, học sinh cần hiểu cách các máy tính "nói chuyện" trên mạng:

  • Thiết bị đóng vai trò gì? Điện thoại của bạn là Client. Chip ESP32 đóng vai trò là Web Server, chờ đợi các yêu cầu gửi đến.
  • Kết nối như thế nào? ESP32 dùng lệnh network.WLAN() kết nối vào cục Wi-Fi nhà bạn và lấy một địa chỉ IP (VD: 192.168.1.50).
  • Xử lý Request (Socket): Khi Client vào IP đó, ESP32 sẽ gửi trả (Response) một trang HTML chứa nút bấm. Nếu Client bấm nút "ON", URL thay đổi thành /?led=on, ESP32 sẽ phân tích chuỗi này để cấp điện cho đèn.

Tư duy Giao thức mạng

2

Lập Trình MicroPython (Thonny IDE)

Học sinh sử dụng thư viện socket để mở cổng 80 và phân tích chuỗi HTTP truyền đến.

main.py - Thonny
import machine
import network
import socket

# Thiết lập chân GPIO điều khiển đèn
led = machine.Pin(2, machine.Pin.OUT)

# Hàm HTML tạo giao diện Web
def web_page():
    html = """<html><head><meta name="viewport" content="width=device-width, initial-scale=1"></head>
            <body><h1>ESP32 Smart Home</h1>
            <a href="/?led=on"><button>Bật Đèn</button></a>
            <a href="/?led=off"><button>Tắt Đèn</button></a>
            </body></html>"""
    return html

# Mở Socket lắng nghe cổng 80 (HTTP)
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.bind(('', 80))
s.listen(5)

while True:
    conn, addr = s.accept()
    request = conn.recv(1024)
    request_str = str(request)
    
    # Xử lý Logic
    if '/?led=on' in request_str:
        led.value(1)
    elif '/?led=off' in request_str:
        led.value(0)
        
    # Gửi trả trang Web cho điện thoại
    response = web_page()
    conn.send('HTTP/1.1 200 OK\n')
    conn.send('Content-Type: text/html\n\n')
    conn.send(response)
    conn.close()

Triển Khai & Bài Tập Mở Rộng

Các bước thao tác trong Thonny:

  • 1. Chạy Code Trực Tiếp: Bấm F5 trên Thonny, không cần biên dịch tốn thời gian. Khung Shell sẽ báo địa chỉ IP ngay lập tức (VD: 192.168.1.100).
  • 2. Test trên Điện Thoại: Mở Safari/Chrome, nhập IP vào. Bấm nút và quan sát đèn LED hoặc rơ-le (Relay) trên mạch đóng ngắt "tách tách".
  • 3. Lưu vào Thiết Bị: Lưu file với tên main.py vào bộ nhớ của ESP32. Rút cáp máy tính, cắm sạc dự phòng, hệ thống sẽ tự chạy độc lập!

Thử thách Web Design

Trang web hiện tại đang rất xấu. Học sinh được yêu cầu tự học thêm CSS cơ bản để làm nút bấm to hơn, đổi màu xanh/đỏ tương ứng và thêm thông số Nhiệt độ phòng (đọc từ DHT11) lên trang web.
