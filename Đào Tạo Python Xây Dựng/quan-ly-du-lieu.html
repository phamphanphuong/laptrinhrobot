Tuần 7–8 · Kho Lưu Trữ Dữ Liệu

SQLite, KhachHang, DuAn và CRUD

B13–B16
  1. B13
    Khởi tạo SQLiteTạo bảng KhachHang để lưu thông tin khách hàng.
    Bài tập tổng kết: Tạo database và bảng khách hàng có khóa chính.
    Hiện source code mẫu
    import sqlite3
db = sqlite3.connect("cong_trinh.db")
db.execute("CREATE TABLE IF NOT EXISTS KhachHang (id INTEGER PRIMARY KEY, ten TEXT, sdt TEXT)")
db.commit()
  2. B14
    Khởi tạo DuAnLưu thông tin công trình và liên hệ dự án với khách hàng.
    Bài tập tổng kết: Tạo bảng dự án và liên kết dự án với khách hàng.
    Hiện source code mẫu
    db.execute("CREATE TABLE IF NOT EXISTS DuAn (id INTEGER PRIMARY KEY, ten TEXT, khach_hang_id INTEGER)")
db.commit()
  3. B15
    CRUD — Thêm và ĐọcThêm bản ghi mới, sau đó lấy danh sách để kiểm tra.
    Bài tập tổng kết: Thêm một khách hàng và đọc lại danh sách.
    Hiện source code mẫu
    db.execute("INSERT INTO KhachHang (ten, sdt) VALUES (?, ?)", ("Nguyen Van A", "0900000000"))
      db.commit()
      for row in db.execute("SELECT * FROM KhachHang"):
        print(row)
  4. B16
    CRUD — Sửa và XóaCập nhật trạng thái và xóa bản ghi mẫu khi cần.
    Bài tập tổng kết: Cập nhật trạng thái một khách hàng rồi xóa bản ghi thử nghiệm.
    Hiện source code mẫu
    db.execute("UPDATE KhachHang SET sdt = ? WHERE id = ?", ("0911111111", 1))
db.execute("DELETE FROM KhachHang WHERE id = ?", (99,))
db.commit()

Pandas hay SQLite?

Pandas phù hợp khi bạn đang phân tích một bảng đang có trong bộ nhớ: lọc, sắp xếp, kiểm tra.

SQLite phù hợp khi dữ liệu cần được lưu bền vững, có nhiều bảng và cần CRUD.
