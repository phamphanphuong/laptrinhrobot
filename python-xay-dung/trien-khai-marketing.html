    Mục tiêu: Học viên hiểu đường đi từ code Python trên máy tính → GitHub Repository → Cloud Server → Màn hình điện thoại; tạo file requirements.txt chuẩn.

    💡 Bẫy lỗi thường gặp & Mẹo sư phạm

    • Thiếu file requirements.txt: Server không biết máy học viên cài những thư viện gì nếu không có file này. Giảng viên hướng dẫn: "File requirements.txt giống như bảng kê vật liệu gửi cho nhà máy".

    🛠️ Bài tập thực hành tại lớp

    Bài 1 (Cơ bản): Tạo file requirements.txt chứa các thư viện cần thiết: streamlit, pandas.
    Bài 2 (Thực chiến nâng cao): Dùng lệnh Terminal pip freeze > requirements.txt để tự động xuất phiên bản chính xác các gói thư viện đang cài đặt.

    Mục tiêu: Học viên không sợ màn hình đen của Linux; biết cách kết nối SSH và chạy ứng dụng Streamlit ở chế độ nền (background process).

    💡 Bẫy lỗi thường gặp & Mẹo sư phạm

    • Tắt cửa sổ SSH làm tắt luôn App: Nếu chạy streamlit run app.py thông thường, khi đóng cửa sổ terminal thì app cũng chết theo! Dạy lệnh nohup streamlit run app.py & hoặc dùng tmux để giữ app luôn sống.

    🛠️ Bài tập thực hành tại lớp

    Bài 1 (Cơ bản): Viết kịch bản dòng lệnh Linux tải mã nguồn từ GitHub về thư mục /var/www/remodeling-crm.
    Bài 2 (Thực chiến nâng cao): Viết lệnh mở cổng mạng firewall (UFW) cho cổng 8501: sudo ufw allow 8501.
    Bash Shell · Kịch bản chạy trên máy chủ VPS B26deploy_vps.sh
    #!/bin/bash
# BUỔI 26: KỊCH BẢN TỰ ĐỘNG CHUẨN BỊ MÁY CHỦ UBUNTU
echo "=== BẮT ĐẦU THIẾT LẬP MÁY CHỦ REMODELING CRM ==="

# 1. Cập nhật hệ điều hành
sudo apt update && sudo apt upgrade -y

# 2. Cài đặt Python và Pip
sudo apt install -y python3-pip python3-venv git

# 3. Tạo môi trường ảo và cài đặt thư viện
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 4. Mở cổng mạng tường lửa cho Streamlit
sudo ufw allow 8501/tcp

# 5. Khởi động app chạy nền độc lập
nohup streamlit run mini_crm_app.py --server.port 8501 --server.address 0.0.0.0 > app.log 2>&1 &
echo "✅ App đang chạy nền tại cổng 8501! Kiểm tra nhật ký: tail -f app.log"
